# DS컴퍼니 소셜벤처 IR 피칭 상호평가 웹앱

## 주요 기능
- 8개 학급, 각기 다른 팀 수(학급당 2~20팀)
- 학생별 12자리 무작위 일회용 평가코드(학급·소속 팀에 결합)
- 본인 팀 제외 모든 팀 평가, 사회적 가치 40 / 수익 가능성 30 / 실현 가능성 30, 5점 단위
- 모든 팀 평가 완료 후 1회 최종 제출, 서버 측 자기 팀 평가·중복 제출 검증
- 관리자 인증, 반별 평가 시작·마감, 5초 간격 자동 갱신, 팀별 평균 및 순위
- 학급별 QR PNG, 일회용 코드 CSV, 결과 CSV 다운로드
- SQLite 로컬 저장소. 학생 실명·전화번호 수집 불필요

## 빠른 시작 (Python 3.10 이상)

1. Python 설치 후 터미널에서 `pip install "qrcode[pil]"` 실행 (QR 이미지 기능에만 필요)
2. 관리자 비밀번호와 공개 접속 URL 설정

Windows PowerShell:
```powershell
$env:IR_ADMIN_PASSWORD="여기에_12자_이상의_안전한_비밀번호"
$env:IR_BASE_URL="http://192.168.0.10:8080"
python server.py
```

macOS / Linux:
```bash
export IR_ADMIN_PASSWORD='여기에_12자_이상의_안전한_비밀번호'
export IR_BASE_URL='http://192.168.0.10:8080'
python3 server.py
```

- `IR_BASE_URL`은 **학생 스마트폰에서도 접속 가능한 주소**여야 합니다. `localhost`는 학생 휴대전화에서 작동하지 않습니다.
- 강사용: `http://서버주소:8080/admin`
- 학생용: `http://서버주소:8080/c/1` ... `/c/8`
- 같은 와이파이에서 접속하려면 서버 PC의 사설 IP를 사용하고 방화벽에서 TCP 8080 허용이 필요합니다.
- 외부 인터넷에서 이용할 때는 HTTPS 지원 호스팅/리버스 프록시를 구성해야 합니다. 관리자 비밀번호와 평가코드를 HTTP로 전송하는 공개 배포는 금지합니다.
- 재시작 시 관리자 로그인은 해제되고 학생의 임시 세션도 해제됩니다. 제출된 평가는 SQLite에 유지됩니다.

## 강사 운영 순서
1. `/admin` 로그인
2. 학급(1~8반)을 하나씩 선택하고 팀 이름을 줄바꿈으로 입력 후 저장
3. 팀별 학생 수에 맞게 일회용 평가코드 발급 → 생성 즉시 내려받은 CSV 안전하게 보관
4. 반별 QR PNG 저장 및 학생에게 안내, 학생마다 자신의 소속 팀에 해당하는 코드를 한 개씩 배부
5. 해당 반의 `평가 시작` 클릭
6. 학생이 QR 접속 → 코드 입력 → 자기 팀 제외 모든 팀 평가 → 최종 제출
7. 관리자 화면에서 제출 수와 점수 확인 → `평가 마감` → 결과 CSV 저장

## 점수 집계
각 팀의 사회적 가치/수익 가능성/실현 가능성 점수를 각각 산술평균하고, 팀별 총점은 평가자가 매긴 100점 만점 총점의 산술평균으로 계산합니다. 팀별 평가 인원과 미응답 인원을 함께 확인하세요.

## 데이터 구조
- `classes`: id, name, status(draft/open/closed), show_results(향후 확장용)
- `teams`: id, class_id, name
- `voters`: id, class_id, team_id, code_hash, code_hint, submitted_at
- `ratings`: voter_id, target_team_id, social, profit, feasible

코드 원문은 데이터베이스에 저장하지 않고 SHA-256 해시만 저장합니다. 원문은 발급 순간 CSV로만 제공합니다. `ir_data.sqlite3` 파일은 백업 및 접근 제한이 필요합니다.

## 주의 / 운영 한계
- 본 버전은 **시범 운영 및 단일 서버 배포용**입니다. 인터넷에 공개하기 전 HTTPS, 서버 방화벽, 보안 모니터링, 백업, 관리자 계정 잠금/로그인 속도 제한, CSRF 보호, 평가코드 입력 시도 제한, 서버 재시작 후 세션 복구 등의 보강이 필요합니다.
- 일회용 코드의 소속 팀은 강사가 발급 시 지정합니다. 학생이 다른 학생의 코드를 사용하지 않도록 **개별 배부**해야 합니다.
- 관리자 화면은 5초 간격 자동 갱신으로 엄밀한 의미의 웹소켓 실시간은 아닙니다.
- QR 코드는 `IR_BASE_URL` 기준으로 생성되므로 서버 주소를 먼저 확정한 후 출력하세요.
- `IR_SESSION_SECRET`을 고정 설정하면 관리자 로그인 서명키가 재시작 후에도 유지됩니다. 운영 서버에서는 32자 이상 임의 문자열을 사용하세요.
- 학급 상태를 '마감'한 후 재시작할 수는 있지만, 마감 중에는 추가 코드 발급이 제한됩니다.
- 학생에게 결과를 공개하는 기능은 아직 제공하지 않으며 강사만 조회할 수 있습니다.
